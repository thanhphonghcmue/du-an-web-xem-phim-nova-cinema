## Chạy website với dữ liệu PostgreSQL thật

Cấu hình kết nối native của bạn trong `backend/.env`, sau khi pull main:

```sh
npm run setup:local
npm run dev:native
```

`dev:native` đặt `NOVA_REQUIRE_DATABASE=true` và chọn PostgreSQL. Lệnh dừng với exit1 nếu DB/Redis không sẵn sàng, seed/build lỗi hoặc health không đạt; không tự chuyển phiên này sang RAM. Lệnh `dev` cũ vẫn giữ hành vi tương thích. Các ca test orchestration dùng stub được ghi rõ là stub; smoke thực đã gọi `/api/v1/health` qua Next.js và đối chiếu cả ba trạng thái UP.

Điều kiện nghiệm thu trên máy nhóm: PostgreSQL/Redis native sẵn sàng và có đúng cấu hình riêng; `TEST_DATABASE_URL` dùng database riêng cho hai script test. Mật khẩu/token/.env và dữ liệu log thực không được commit.
